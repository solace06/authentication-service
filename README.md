# Project Title
Authentication Service

# Motivation
The Authentication Service is a learning-focused project designed to understand and implement essential backend concepts such as JWT-based authentication, password hashing, rate limiting, middleware, API security, and database integration.
The goal is to build a practical authentication system while gaining hands-on experience with designing and structuring a production-oriented Go backend service.

# Tech/Framework Used
- **Language:** Go
- **Web Framework:** Gin
- **Database:** PostgreSQL
- **ORM:** Bun
- **Database Driver:** pgx
- **Authentication:** JWT
- **Password Hashing:** bcrypt
- **Validation:** go-playground/validator
- **Database Migrations:** golang-migrate
- **Containerization:** Docker & Docker Compose
- **API Testing:** Postman
- **Version Control:** Git
